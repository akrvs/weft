# M16

Status: planned
Started: 2026-09-14

## Goal

Loose ends from M15. The relay sweep and the blob protect set become
table lookups instead of a decode of every stored record once a minute,
the gateway's pull budget survives a restart, and the negative DNS path
has a unit test against a fake name server. No protocol change. The
demo: a relay with thousands of records sweeps without decoding one; a
gateway restarted mid hour still refuses the identity that spent its
budget; `cargo test -p weft-resolve` exercises NXDomain, an empty answer,
two records and a malformed value without the network.

## Decisions

| Topic | Decision |
|---|---|
| Index tables | Two derived tables in the redb index: `authors`, a multimap from author to record address, and `blobs`, from record address to the blob it names. Maintained on every insert and remove. Rebuilt from `records` once at open when `authors` is empty and `records` is not, so an existing relay upgrades in place with one scan |
| Sweep | Iterates `authors`, skips allowlisted authors whole, and for the rest keeps a record only if it holds a live pin or is the current manifest of a paying author. A dropped record leaves `records`, `authors`, `blobs`, its head entries under the author's prefix and its manifest entry. No pass decodes a record |
| Protect set | `blobs()` returns the values of the `blobs` table |
| Budget file | `<home>/gateway/budget`, canonical CBOR, mode 0600, loaded at start, rewritten after every charge with expired windows pruned, at most 1024 identities. A bad file refuses to start, like sessions. A charge follows a relay pull, so the write is off the fast path |
| Fake DNS | A `cfg(test)` constructor builds `Dns` over a plain UDP name server. The test runs a loopback UDP responder built from `hickory-proto` messages. No new dependency, no production surface |
| Dependencies | Nothing new |

## Layout

```
crates/net/src/index.rs          authors and blobs tables, rebuild at open, sweep by author
crates/net/tests/relay.rs        an upgraded index rebuilds its tables, sweep drops blobs entries
crates/gateway/src/budget.rs     load, save, path, cap
crates/gateway/src/lib.rs        budget path from home
crates/resolve/src/dns.rs        cfg(test) udp constructor, fake server tests
docs/relay.md, docs/store.md     index tables, budget file
README.md                        badges, counts
```

## Plan

1. Index: add the two tables, maintain them in `insert` and on removal,
   rebuild at open, rewrite `sweep` to iterate `authors`, `blobs()` reads
   the table. Test: open an index written without the tables and check
   the sweep and protect set still see every record.
2. Budget: `Budget::open(path, bytes, window, now)` loads the file;
   `charge` prunes and saves; a bad file refuses. Tests: a restart keeps a
   spent window, an expired window is dropped on load, a bad file refuses.
3. DNS: `Dns::udp(addr)` under `cfg(test)`; a fake server answering by
   query name; tests for the four negative shapes plus a positive binding
   with the AD bit and a cached miss for the SOA minimum.
4. Docs, README, smoke test the real binaries, close.

## Out of scope

- Any protocol or wire change.
- Budget windows shared across gateway instances.
- A real hickory server or DoH in the fake.
