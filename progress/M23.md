# M23

Status: planned
Started: 2026-09-22

## Goal

Make the repository something a second person can use, read, and watch.
The code carries no license although the repository is public. The design
document promises features the code never grew and calls settled questions
open. Nothing has ever been tagged and nothing shows the loop without
building it. This milestone adds the license, brings the design document
level with the code, cuts a first tag with a release, and records a two
minute demo of the loop with a script that anyone with the tools can rerun.

## Decisions

| Topic | Decision |
|---|---|
| License | Apache-2.0. `LICENSE` at the root, `license = "Apache-2.0"` in `workspace.package`, every crate inherits it. `publish = false` stays; nothing goes to crates.io |
| Version | The workspace stays at 0.1.0. The tag is `v0.1.0` on the landed close commit, annotated. A GitHub release carries short notes and the demo video and GIF. No binaries; the README builds from source |
| Design document | `docs/design.md` becomes version 0.1 dated 2026-09-22. The prose stays as the vision. A status table under the layer stack names each promise the document makes and marks it shipped, partial, or deferred with the section that holds the rule. The roadmap gains the M8 to M23 rows. The open questions list holds what is still open. The shared artifact is regenerated from the same content |
| Deferred, not cut | Petnames, label lists, selective disclosure claims, root rotation by a successor manifest, hardware backed roots, signed snapshots of HTTPS pages, an identity switcher, readers paying authors, DHT discovery, relay gossip, and publishing by drag and drop stay in the document as deferred and become `BACKLOG.md` rows with the section that describes them |
| Demo | `crates/browser/demo.sh` builds the release binaries, stands up two homes, a relay, and a bank under `WEFT_NET=local`, publishes from home A on the CLI while writing an asciicast, then opens the browser as home B on the drive socket, walks the loop, and captures the window with `grim` at 8 frames per second. `agg` renders the cast, `ffmpeg` cuts title cards with `drawtext`, joins the segments, and writes `target/demo/weft-0.1.mp4` (H.264, 1280 wide) and `weft-0.1.gif` (960 wide). Nothing is committed but the script |
| Shared helpers | The drive socket helpers `js`, `ok`, `expect`, `wait_js`, `set_value`, `click`, `submit`, and the window geometry lookup move from `smoke.sh` to `crates/browser/drive.sh`, sourced by both scripts. `smoke.sh` behaves as before |
| Gateway in the demo | Firefox opens the gateway page over loopback and its window is captured for a few seconds, the M4 demo as written. If Firefox cannot be driven headlessly enough the segment becomes a card with the `curl -i` transcript |
| Dependencies | None in Cargo. The demo needs `grim`, `hyprctl`, `socat`, `jq`, `agg`, `ffmpeg` with `drawtext` and `libx264`, and `firefox`; the script checks each and names the missing one |

## Layout

```
LICENSE                                Apache-2.0
Cargo.toml                             license in workspace.package
crates/*/Cargo.toml                    license.workspace = true
docs/design.md                         version 0.1, status table, roadmap rows, open questions
crates/browser/drive.sh                shared drive socket helpers
crates/browser/smoke.sh                sources drive.sh
crates/browser/demo.sh                 the recorded loop
README.md                              license badge, release flag, demo link, loadout, ops
progress/HANDOFF.md                    repo line, where we are
progress/BACKLOG.md                    deferred design promises
```

## Plan

1. License file and manifest fields. `cargo deny check licenses` and
   `cargo metadata` agree on every crate.
2. Rewrite `docs/design.md`: header, layer table, the status table, the
   roadmap rows, the open questions. Every row cites the protocol section
   or crate that implements it.
3. Extract `drive.sh`, run `smoke.sh` unchanged to prove nothing moved.
4. Write `demo.sh`: setup, the cast, the browser walk under the frame
   grabber, the Firefox segment, the ffmpeg assembly. Run it, watch the
   result, tune the pacing.
5. Regenerate the artifact from the new `design.md` and republish it to
   the same URL.
6. Close: M23 file, handoff, backlog, README. Verify, push, CI.
7. Land on main. Tag `v0.1.0`, create the release with the notes, the
   MP4, and the GIF.

## Out of scope

- Binaries on the release page.
- Publishing crates to crates.io.
- A CI job that records the demo.
- Any protocol or code change beyond manifest metadata.
