# M18

Status: planned
Started: 2026-09-14

## Goal

Empty the backlog of everything that is not browser polish, so M19 can be
the browser alone. Eleven rows close: a lost key is retired instead of
revoked and keeps its earlier records, a receipt may pay for any author's
records, grants cover fetched records, an app is shown by the title of
its own page, the store answers from an index instead of a directory
walk, a detached daemon logs to a file and stops on request, relay list
entries may carry addresses, the gateway routes by `Host` and keeps its
tables in redb, and two rows close by a recorded decision: the payment
rail stays the voucher, the live `_weft` record is verified on the fake
alone. The demo: retire a device, its old page still renders and its new
one does not; a stranger pays to pin a friend's page; `weft grant list`
names the app; a store of 10 000 records answers a read without touching
the directory; the browser stops a daemon it did not start; a relay across
a subnet is reached by `id@host:port`; `curl -H 'Host: alice.example'
gateway/` serves `alice.example/home`.

## Decisions

| Topic | Decision |
|---|---|
| Lost key | `weft device retire <label> [--at <unix>]` sets `expires` on the device entry, default now; the key stays in `devices`. Records `created` before `expires` keep verifying, later ones are `expired`. `revoke` stays retroactive for a compromised key. No manifest field is added: `expires` already carries the meaning, and `protocol.md` says so and names the cost, a retired key's holder can backdate `created`. Deviates from the answer to reopen the format; the outcome is the same with no vector churn beyond two new entries |
| Sponsorship | A receipt pays for any records it names that are in the batch or already stored. The relay drops the author check; the sweep keeps the newest manifest of every author who holds a pin or whose record does. `protocol.md` and `relay.md` lose the own author sentence |
| Fetched grants | `list` and `get` under a grant cover every locally held record of the kind that verifies against its author's newest local manifest. `put` stays root only. A grant now reveals which foreign records the store holds, said in `store.md` |
| App names | `Resolver::title(author)` reads the head of `author/home` locally, never pulling, and returns the first heading of the page if the body is Markdown. `weft grant list` and the browser grants table show `title (address)` or the address alone. No protocol change |
| Store index | `Store` keeps an in memory index of record metadata, `address`, `author`, `kind`, pointer `name`, built by one walk and reused while the records directory's mtime is unchanged and at least one second older than the walk that read it. `Snapshot` loads records through the cache only when a method asks for them. redb is not used here: the CLI writes to the same directory from its own process and redb holds one process lock. Deviates from the answer |
| Detach | The daemon writes every line after start to `<home>/store.log`, mode 0600, rotated to `store.log.1` past 1 MiB; a start failure still prints to stderr. `Request::Stop` is browser only and ends `serve`; `weft-store stop` sends it with `<home>/browser.key`; the browser store view shows the log tail and a stop button for attached and detached daemons alike |
| Addressed relays | A relay list entry is `<id>` or `<id>@<host:port>[,<host:port>]`, parsed into `weft_home::Relay { id, addrs }`, which converts to `EndpointAddr`. `weft relay add` takes the same text; `weft-relay serve` prints its direct addresses after the id so the entry can be copied |
| Gateway host | The `Host` header, without port, that differs from the `--origin` host is a publisher host. A path that does not parse as a target on such a host is read as `<host>/<path>` with `/` meaning `home`. Login challenges name the request's host under the origin's scheme, so a cookie works on the host the browser used. TLS stays at the reverse proxy, frozen |
| Gateway tables | Sessions and budget windows live in `<home>/gateway/state.redb`, one row per entry, loaded into memory at start, written row by row. `--sessions` and `--identities` keep their eviction rules with no `cbor::MAX_ITEMS` bound. The old `sessions` and `budget` files are not read |
| Closed by decision | The voucher is version 1's rail; `design.md` records that a real rail sits behind `Relay::settle` in a later version. No public domain carries a `_weft` record; the positive DoH path and the AD bit are tested on the loopback fake alone, recorded in the handoff |
| Dependencies | `redb` 4.2 in `weft-gateway`, already pinned in the workspace. Nothing else |

## Plan

1. Retire: `Home::retire`, `weft device retire`, protocol section 7 text,
   two vectors, a test that a page before `expires` verifies and one
   after does not.
2. Sponsorship: drop the author checks in `settle` and `stored_size`,
   widen the sweep, docs. Test: a stranger pins a friend's page and its
   manifest survives the sweep; the friend's unpinned page does not.
3. Store index: `Index`, `Snapshot` methods load on demand, mtime guard.
   Tests: a snapshot after no change opens no record file, a write is
   seen, a deletion is seen, the resident set stays under the cap.
4. Fetched grants: `View::readable(kind)` over every author; docs.
   Tests: a granted app lists a fetched record; a record whose author's
   manifest revoked its signer is not listed; `put` for another author is
   refused.
5. Log and stop: `Log`, `Request::Stop`, `weft-store stop`, browser
   panel and button. Tests: stop from a grant key is refused, stop from
   the browser key ends `serve`, the log rotates.
6. Titles: `render::heading`, `Resolver::title`, CLI and browser. Tests:
   a heading is found, a blob body yields none, a missing page yields none.
7. Addressed relays: `Relay` parse and display with negative cases, the
   relay list round trip, the client dials a loopback relay by address
   with no mDNS answer, `weft-relay serve` prints addresses.
8. Gateway state: `state.rs` with two tables, login and budget over it,
   caps without the CBOR bound. Tests rewritten on the same fixtures; a
   garbage state file refuses.
9. Gateway host: publisher host fallback, per host login origin, an
   invalid host answers 400. Tests: `Host: alice.example` with `/` and
   `/about`, a full target path on a publisher host, the origin host
   unchanged.
10. Docs and closures: `design.md` rail and revocation, handoff gotcha for
    the DoH fake, backlog rows removed. Smoke test every binary,
    screenshot the browser store view with the stop button.

## Out of scope

  management, history and bookmarks, non image blob view, passphrase
  field after a failed start, blob download progress, browser price and
  pay, `weft:` URL handler registration. They are M19.
- TLS in the gateway process.
- A payment rail behind the voucher.
